# DeskPilot MCP 与运行控制增强计划

目标：把实时 IT 状态与静态知识结合，提供可运行的 MCP 接入，同时让权限、工具契约、故障与审计有明确边界。

采用受控诊断方案：本地 MCP 示例提供服务状态与设备查询；可配置一个经过维护人审核的远程 HTTPS MCP 服务。相比只增加工具按钮，此方案接入诊断流程；相比开放式多 Agent 自主写入，它保留可验证的审批和幂等边界。

## 安全与实现约束

MCP 工具声明属于不可信元数据，工具的可用权限来自本地审核契约。调用只读且显式执行，不接受通用任意工具、命令或 URL。远程工具失败不自动重试，以免未确认的远端行为重复发生；连续失败触发熔断，管理员可重置。结果经过类型验证、大小限制和脱敏，仅保留本地运行记录。接入真实服务之前必须确认其工具实现、认证和数据权限；本地演示身份不能用于公网部署。

单进程运行；现有 SQLite、Qdrant 与 LangGraph checkpoint 不宣称跨系统原子事务。SDK 解码后的结果上限不等同于底层网络内存上限。DNS/出站策略依然需要部署层网络控制；并发撤权无法撤回已发出的请求。真实远端 MCP 与千问效果没有凭据时标记未验证。
