# IT 专用：VPN 网关事件交接手册

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：星桥VPN；适用版本：运维 5.2。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

同一时间多名员工报告 VPN 无法建立，需要 IT 判断是否为网关事件。

## 判断依据

本文面向 IT 和管理员，员工检索不得返回操作细节，且内容不得送往云端。

## 处理步骤

1. 在批准的监控平台核对事件时间与影响范围，不由 Agent 登录网关。
2. 关联已存在事件工单，汇总客户端版本、网络区域及错误码分布。
3. 由值班负责人确认维护窗口，任何配置变更需变更审批与回退记录。
4. 恢复后对受影响用户分组验证，更新事件时间线与复盘候选知识。

## 验证与完成条件

事件工单有责任人、验证结果和变更编号，员工端只收到允许发布的状态。

## 权限与风险边界

本文不含网关地址、口令或实际配置命令，不能直接用于生产变更。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
