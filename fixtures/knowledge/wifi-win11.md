# Windows 11 办公 Wi-Fi 连接但无法上网

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：办公网络；适用版本：Windows 11。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

无线图标显示已连接，但浏览器提示无 Internet，VPN 尚未启动。

## 判断依据

先区分 Wi-Fi 认证、门户登录和 DNS 问题，保留当前网络名称，不直接重置全部网络配置。

## 处理步骤

1. 确认连接公司员工网络而非访客网络，打开浏览器查看是否有登录门户。
2. 仅对当前员工网络执行断开再连接，避免忘记所有已保存网络。
3. 确认飞行模式关闭，检查系统日期时间，尝试打开两类公开网页。
4. 若同位置多人同时故障，记录位置与时间提交网络事件，避免每人重复重装驱动。

## 验证与完成条件

公网访问稳定后再测试 VPN；应分别记录公网和内网结果。

## 权限与风险边界

员工不应卸载网卡驱动或恢复全部网络设置，涉及受管配置需由 IT 处理。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
