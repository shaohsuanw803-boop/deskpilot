# 收到可疑登录邮件：报告而非点击

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：邮件安全；适用版本：通用。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

邮件声称账号马上停用，要求在陌生页面输入密码和验证码。

## 判断依据

紧迫措辞、异常域名和索要验证码是风险信号，但服务台应基于证据核验。

## 处理步骤

1. 不要点击链接、下载附件或回复验证码。
2. 使用邮件客户端内的报告可疑邮件入口提交原始邮件。
3. 如已输入凭据，通过已知的公司门户更改密码并立即联系安全团队。
4. 记录点击时间和是否提交信息，不把密码本身写入工单。

## 验证与完成条件

安全团队收到事件，受影响账号按流程处置，用户停止与可疑页面交互。

## 权限与风险边界

Agent 不访问可疑站点尝试登录，也不公开转发完整钓鱼内容。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
