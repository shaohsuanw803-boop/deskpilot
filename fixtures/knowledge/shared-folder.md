# 共享文件夹无权限：申请而非借用账号

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：文件服务；适用版本：Windows 11。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

能看到共享文件夹名称，但打开时提示拒绝访问。

## 判断依据

文件夹可发现不代表拥有读取权限，应核对业务用途、所属部门与数据责任人。

## 处理步骤

1. 确认使用本人企业账号，关闭通过个人账号建立的旧连接。
2. 在工单写明文件夹显示名称、业务用途和所需权限级别，不上传内部文件副本。
3. 由文件夹责任人审核读或写权限，再由 IT 执行授权。
4. 授权后重新登录文件服务并仅验证申请范围内的目录。

## 验证与完成条件

申请人能读取被批准目录，未申请目录仍被拒绝。

## 权限与风险边界

不得借用同事账号、复制他人的访问令牌或申请整盘管理员权限。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
