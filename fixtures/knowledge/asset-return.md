# 离职设备归还：交接与保留业务资料

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：资产管理；适用版本：通用。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

员工需要归还电脑，设备上仍有工作文档和个人账号。

## 判断依据

业务归档、个人退出登录和设备擦除由不同责任人处理，不能未经确认清空硬盘。

## 处理步骤

1. 与主管确认业务资料交接清单和接收人，使用公司受管空间移交。
2. 退出个人账号并删除个人快捷入口，不删除受保留策略管理的业务文件。
3. 归还资产时核对资产编号、配件和签收记录。
4. 由授权 IT 在保留要求满足后执行设备重置，员工不自行格式化。

## 验证与完成条件

接收人确认业务资料可用，资产台账完成签收。

## 权限与风险边界

Agent 不提供规避企业保留策略的删除方案。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
