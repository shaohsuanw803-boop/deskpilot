# macOS 存储不足：查看分类并申请归档

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：终端管理；适用版本：macOS 14。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

Mac 系统提示存储已满，应用保存文件失败。

## 判断依据

macOS 系统数据分类不等于可随意删除，先确认个人大文件和下载内容。

## 处理步骤

1. 在系统设置的通用、储存空间查看主要占用分类。
2. 保存工作并核对大文件是否已有受管备份，不直接删除唯一副本。
3. 仅清理已确认不需要的个人下载副本，团队资料按归档流程处理。
4. 系统数据异常膨胀时由 IT 进一步诊断，不运行网上复制的清理命令。

## 验证与完成条件

应用能保存文件，受管同步与备份状态正常。

## 权限与风险边界

不删除 Library、系统快照或其他账号目录，不套用 Windows 临时文件路径。

## 升级与知识维护

若完成上述安全检查仍无法恢复，保留错误文字、版本和已尝试步骤创建工单。禁止把密码、令牌或完整业务文件写入工单。修复经验只形成待审核知识，审核通过后才能替换共享版本；旧版本应保留变更记录。
