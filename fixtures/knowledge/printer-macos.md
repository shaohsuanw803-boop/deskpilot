# macOS 14 添加五楼北区打印机

> 虚构演示资料：星河示例公司。仅用于 DeskPilot 测试，不是实际企业操作手册。

## 适用范围

产品：打印服务；适用版本：macOS 14。
责任人：示例 IT 服务台；复核日期：2026-09-29。

## 用户现象

Mac 没有五楼北区打印队列，Windows 同事可正常打印。

## 判断依据

macOS 使用软件中心下发的打印配置，不能安装 Windows 专用驱动包。

## 处理步骤

1. 确认连接员工办公网络并记录 macOS 版本。
2. 在公司软件中心选择 PRN-5F-NORTH 的 macOS 配置。
3. 安装完成后在系统设置的打印机与扫描仪中确认队列。
4. 使用无敏感内容的测试页，检查双面与纸张大小是否正确。

## 验证与完成条件

队列出现在 macOS 系统设置，指定打印机正常输出。

## 权限与风险边界

不手工安装未知来源的驱动或复制其他人的设备证书。
